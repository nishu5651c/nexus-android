# Nexus — Real-Time Collaboration Platform (Android)

This repository contains the Nexus Android project generated by Copilot. It includes a project skeleton, Firebase integration helpers, authentication UI, messaging, workspaces and file upload scaffolding.

Important: Before building, add your Firebase configuration file (google-services.json) to app/. Do NOT commit google-services.json to the repository.

How to open
1. Install Android Studio.
2. File -> Open... -> choose the directory containing settings.gradle.
3. Add app/google-services.json and let Gradle sync.

What is included
- Splash screen, onboarding, auth UI
- Firebase AuthManager and Firestore helpers
- Realtime messaging scaffolding with Room local cache and WorkManager sync
- Workspace creation and file upload UI
- Firestore & Storage rules templates (review before production)
